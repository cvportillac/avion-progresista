📦 ¿Dónde se guardan los resultados?
Estado actual del almacenamiento
Sin Firebase: los datos se guardan en el navegador del dispositivo donde corre la app (localStorage). Si cierras el navegador o cambias de dispositivo, se pierden. Solo útil para pruebas.
Con Firebase (recomendado): los datos se guardan en la nube de Google, gratis hasta 1 GB. Todos los celulares comparten los mismos datos en tiempo real y puedes exportarlos como JSON desde la consola de Firebase.
⚙️ Configurar Firebase (tiempo real)
📋 Pasos para configurar (5 minutos, gratis)
1. Ve a console.firebase.google.com → Crear proyecto
2. Realtime Database → Crear base de datos → Modo prueba
3. Configuración del proyecto → Agrega app web → copia el objeto firebaseConfig
4. En Reglas pega: {"rules":{".read":true,".write":true}}
5. Pega aquí la configuración y guarda.
Sin configurar — usando almacenamiento local
💡 Despliegue gratuito con GitHub Pages
1. Crea un repositorio en github.com
2. Sube este archivo como index.html
3. Settings → Pages → Branch main → Save
4. Comparte la URL: tuusuario.github.io/repositorio 🎉
